# Asfand Yar Khan - Full-Stack Web Developer Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/asfandyar650/asfand-portfolio)

A modern, responsive portfolio and CV website showcasing full-stack web development projects, technical skills, and contact information.

## 🚀 Features
- **Responsive Design**: Mobile-first layout optimized across all modern screen sizes and devices.
- **Theme Switcher**: Seamlessly toggle between dark and light themes (persisted via `localStorage`).
- **Project Showcase**: Highlights full-stack applications with feature lists, tech stack tags, and links.
- **Interactive Contact Features**: Direct WhatsApp chat integration, one-click phone copy to clipboard, and message form.
- **Print / PDF CV Export**: Built-in print styling to export a clean CV as a PDF.

## 🛠️ Built With
- **HTML5** (Semantic structure & Accessibility)
- **CSS3** (Custom properties, Flexbox, CSS Grid)
- **JavaScript (ES6+)** (DOM manipulation, theme management, clipboard interaction)
- **Font Awesome 6** (Modern icon set)

## 💻 Local Preview
Simply open `index.html` in any web browser, or serve it using a local development server:
```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx)
npx serve .
```
